# Staff / Lead Data Science Portfolio

A Quarto portfolio designed to demonstrate product analytics, experimentation,
machine learning, SQL, Python, R, visualization and technical leadership.

## Local setup

1. Install Quarto, Python and R.
2. Create a Python environment:
   `python -m venv .venv`
3. Activate it and install packages:
   `pip install pandas matplotlib scikit-learn jupyter streamlit plotly`
4. In R:
   `install.packages(c("tidyverse", "pwr", "knitr"))`
5. Preview:
   `quarto preview`
6. Render:
   `quarto render`

Replace placeholders in `_quarto.yml`, add `resume.pdf`, and rewrite the case
studies using anonymized or synthetic data.
